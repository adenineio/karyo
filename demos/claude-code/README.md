# Claude Code, explained

A series of twenty-one short Karyo explainers in five tracks (start here, the text world, how Claude Code works,
setting up your world, reaching beyond your machine) plus a map of the order to read them in, written for people
new to the terminal and to Claude Code. Every company, person, file and folder in it is a made-up example. It ships
with Karyo as a demonstration: `/karyo:demo` (or `karyo demo claude-code`) builds each explainer to one HTML file
and opens the map, which links to all of them. The sources here are plain explainer specs (`*.explainer.json`) and
their components, so they also show what a finished series looks like.
